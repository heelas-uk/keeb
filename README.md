# Keeb
A project for hackclub ~keeb~ forge YSWS 

It's a stenography keyboard. It is custom because my keyboard doesn't have proper n key roll over. This is also my first time in cad and kicad so its bad. 

# How to make

1. Acquire the pcb and 3d model of the case in pla (realistically you should use the one with no top since the top plate isn't essential and a pain to print).

2. Acquire other components per bill of materials

3. Soldering fun. Attach the components with lead free solder.

4. Check it works... kinda really important before you put it in a case

5. Build the case with self tapping screws so there is good stability.

6. Flash the firmware by holding bootsel and drag and drop

7. Install plover HID on you device and plugin via usb

8. It should now work. Yay!
